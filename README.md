# Blog Post Management System

* Frontend: https://blog-post-steel-omega.vercel.app/
* Backend: https://blog-post-nb74.onrender.com/

## Tech Stack

Frontend

* React (Vite)
* Material UI
* Axios
* React Hook Form

Backend

* Node.js
* Express.js
* TypeORM

**Database**

* PostgreSQL

## Features

* Create, Read, Update, Delete (CRUD) blog posts
* Pagination support
* Search (title, author, category)
* Export posts to CSV
* Responsive UI (mobile + desktop)
* Form validation and error handling

---


## 📦 API Endpoints

* GET /api/posts
* POST /api/posts
* PUT /api/posts/:id
* DELETE /api/posts/:id
* GET /api/posts?search=
* GET /api/posts/export
